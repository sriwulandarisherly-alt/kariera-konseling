Karier

Kenali berbagai profesi, tugas, keterampilan, dan jalur pendidikannya.

Teknologi
Programmer / Software Developer

Membuat dan merawat aplikasi serta website. Skill: logika, bahasa pemrograman, kerja tim. Jalur: S1 Informatika / Sistem Informasi, SMK RPL, bootcamp.

Teknologi
Data Analyst

Mengolah data menjadi informasi untuk keputusan. Skill: statistik, Excel, SQL, Python. Jalur: Statistika, Informatika, Sistem Informasi.

Kesehatan
Dokter / Perawat

Merawat dan menangani pasien. Skill: empati, ketelitian, ketahanan mental. Jalur: Kedokteran, Keperawatan, Kebidanan.

Pendidikan
Guru / Pendidik

Mengajar dan membimbing siswa. Skill: komunikasi, kesabaran, kreativitas. Jalur: S1 Pendidikan + PPG.

Bisnis
Akuntan

Mencatat dan menganalisis keuangan. Skill: teliti, jujur, memahami angka. Jalur: Akuntansi, Manajemen.

Kreatif
Desainer Grafis / UI-UX

Membuat desain visual dan tampilan aplikasi. Skill: kreativitas, tools desain, empati pengguna. Jalur: DKV, Desain Produk, SMK Multimedia.

Bisnis
Wirausahawan

Membangun dan mengelola usaha sendiri. Skill: berani mencoba, negosiasi, manajemen. Jalur: Manajemen, Kewirausahaan, pengalaman langsung.

Sosial
Psikolog / Konselor

Membantu orang memahami diri dan masalahnya. Skill: mendengar aktif, empati, etika. Jalur: Psikologi, Bimbingan dan Konseling.
